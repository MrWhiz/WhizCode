| Risk | Mitigation | Fallback |
|------|-----------|----------|
| CoT adds latency | Use for complex tasks only | Disable if >20% slower |
| Confidence inaccurate | Calibrate with real data | Use conservative thresholds |

| Recovery fails | Test thoroughly | Escalate to user |
