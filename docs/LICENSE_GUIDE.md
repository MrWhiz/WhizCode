## Commons Clause Explained

The Commons Clause adds one simple rule to AGPL-3.0:

**"You cannot Sell the Software"**

Where "Sell" means:
- Charging money for the software
- Offering it as a paid service
- Charging for hosting or support
- Any commercial monetization

## AGPL-3.0 Specifics

### Copyleft Requirement
If you distribute WhizCode (modified or not), you must:
1. Include the AGPL-3.0 license
2. Include source code or offer to provide it
3. Document all modifications
4. License derivatives under AGPL-3.0

### Network Service Exception
If you run WhizCode as a network service:
- Users accessing the service must be able to get the source code
- You cannot hide modifications from users
- You must provide source code upon request
- **But you cannot charge for it (Commons Clause)**

**Q: Can I use WhizCode in my company?**
A: Yes, for free. You cannot charge for it.

**Q: Can I modify WhizCode for internal use?**
